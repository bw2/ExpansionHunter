Filtering Interface Overview

  • Drag the dashed red lines to adjust thresholds: points beyond the thresholds will be added to the Excluded list.
  • Dotted gray lines are the suggested thresholds, with points beyond suggested thresholds appearing in orange. Each suggested threshold is times the interquartile range below the 25th percentile or above the 75th percentile of the metric's values on the plotted scale (Tukey's fences). The loci's call rate gets a fixed suggested threshold of instead, since most loci have a call rate of 1.
  • Shift-click a point to select it, or shift-drag a box to select multiple points. Selected points will appear blue on every plot.
  • Right-click selected point(s) and choose "Toggle..." to manually add or remove points from the Exclude list. That overrides the thresholds until you toggle it again or clear it.
  • Edit the reason for an exclusion with the pencil in the tables above, then use the export buttons at the top to export the Exclusion lists. They can then be used as inputs to generate_multisample_tsv.py (--samples-to-exclude and --loci-to-exclude).
  • Everything is saved as you go and restored whenever the dashboard is restarted on the same input file.
